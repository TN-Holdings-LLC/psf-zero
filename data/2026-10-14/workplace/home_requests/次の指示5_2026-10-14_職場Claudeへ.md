## 4. 依頼（優先順。土台は c54。bundle g に入っています）

**R1（最優先）項目 94：3-正則グラフの QAOA を式で組む**

負けている箇所：

| テスト | PSF（T、F） | 利用者の最善（T、F） |
|---|---|---|
| qaoa_n12_p2 | 5.98、4.64 µs | 4.88、3.89 µs |
| qaoa_n20_p2 | 6.31、5.03 µs | 4.43、3.56 µs |

- 利用者の最善は、すべて「辺彩色で層に分けた形」から出ています。基準の作り方は `benchmarks/family_map.py` にあります。
- **まず、層分けの効果とシードの効果を切り分けてください。** 辺彩色で層に分けた形を、QK3 のシード 0 だけで通したときの時間を出してください。シードの変更ではなく、固定した 1 点の測定です。
  - シード 0 だけで PSF に勝つなら、効いているのは層分けです。項目 94 は「可換な ZZ 項を辺彩色の層に並べ直してから、通常経路に渡す」だけで済みます。
  - シード 0 だけでは勝てないなら、効いているのは配置です。その場合は次の案に進みます。
- **式の案（配置が効いている場合）。** 3-正則グラフは、heavy-hex にはそのまま埋め込めません。辺を、決まった規則で「埋め込める部分」と「残り」に分けます。
  - 案 A：全域木（または最大の埋め込み可能な部分グラフ）を VF2 の最初の一致で置きます。残りの辺は、色ごとの層で、決まった規則の SWAP 網（例：N2 の折り返し順）で運びます。
  - 案 B：各色の層は完全マッチングなので、1 層ずつ、線形の SWAP 網で隣り合わせて実行します。
  - どちらも、点数で選ぶことはせず、規則を一つに決めてください。
- 項目 88 の rzz と Pauli フレームを、そのまま使えるようにしてください。
- 比べるもの：c54、QK3、利用者の最善（シード 0 と 5 シードの両方）。T と F の両方です。テストは HW2 の qaoa_n12_p2 と qaoa_n20_p2、C52-VAL の qaoa3reg_n20_r3 です。

**R2（高）項目 93 の許容値を 1e-9 まで締めるための調査**

- 普通の出力に残る 1e-7 程度の差が、どこから来るかを突き止めてください。Weyl のスナップか、浮動小数点の積み重なりか、です。例は FakeTorino の TFIM リングの 6.1e-7 です。
- なお C54-VAL の 208 件では、差の最大が 5.0e-14 でした。1e-7 程度の差は、すべての出力に出るわけではありません。どの回路で出るかも含めて調べてください。
- スナップが原因なら、スナップしない2量子ビット合成を提案してください。例えば、ブロックをまとめたあとの再合成をやめる、などです。
- 出してほしいもの：原因、修正案、修正後に 1e-9 で C52-VAL の全セルが通るかどうか。

**R3（中）Heisenberg の差を詰める**

- heis2d_n16_r1（T）は、PSF 22.27 µs に対して、利用者の最善が 19.69 µs です。次数が 4 なので、項目 91 では埋め込めません。
- 家の確認では、16 量子ビットの heavy-hex の木の上の Heisenberg で、項目 91 を使っても c53 と同じ時間でした（FakeFez F、5.508 µs）。
- 式の案：1 本の辺にかかる XX・YY・ZZ の 3 項は、1 つの2量子ビットゲート exp(i(aXX + bYY + cZZ)) にまとまります。CZ なら 3 個、rzz なら 3 個と1量子ビットゲートで組めます。辺ごとに 3 項を別々に出すより短くなるはずです。
  - 項目 91 の層の中で、この「辺ごとにまとめる」形を使えるか見てください。
