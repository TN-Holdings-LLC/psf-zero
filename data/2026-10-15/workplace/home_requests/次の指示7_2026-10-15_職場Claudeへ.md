### W1（最優先）項目 99：試作 c60（c59 から）

**内容：** 埋め込めるグラフの上の、ネイティブな2量子ビットゲートの回路を、書かれたまま式で組みます。

**対象**

- 項目 96 で範囲の中に入り、かつ `_chain_brickwork` と `_graph_brickwork` の両方が None を返した入力です。今の c59 なら `OutOfScopeError`（"neither formula reads"）になるものです。
- この 2 つの式で組めている入力の出力は、1 ビットも変えないでください（回帰として確認してください）。

**式（どれも、決まった手順を 1 回通すだけです。何も比べません）**

1. **配置：** 項目 91 の `_graph_place` を使います（VF2 の最初の一致、壊れた素子を除く）。
2. **2量子ビットゲート：** 書かれた各ゲートを、その結合器の上で、ネイティブな形にします。
   - cz はそのままです。
   - cx は、標的側の H、cz、H にします。
   - rzz は、Target に rzz があればネイティブにし、項目 86 と同じく範囲に折り返します。なければ cz、rz、cz にします。
   - cp、crz、rxx、ryy、iswap、その他の固定した2量子ビットゲートは、閉じた形の分解（KAK、cz 基底）にします。どれも決まった式で、探索ではありません。
   - 3 量子ビット以上のゲートは、すでに範囲の外です。
3. **可換な対角ゲートの並べ直し：** cz、cp、crz、rzz と、間にある rz は、互いに可換です。対角でないゲートが間に挟まらない区間ごとに、そうしたゲートを辺の彩色（項目 91 の `_graph_colours`）の順に並べ直します。
   - 書いたとおりの順で鎖の cz を並べると、ASAP でも深さが n − 1 になることがあります。彩色すれば、深さは 2（鎖）または 3（ヘビーヘックス）になります。
   - 並べ直しは正確です（可換なので、ユニタリは変わりません）。
4. **1量子ビットの連なり：** 閉じた形（ZYZ）で 1 つにまとめます。T では rz sx rz sx rz、F では rz rx rz です。
   - a20 の `_t_op`、`_mul`、`_zyz` と同じやり方で、PSF 自身で書いてください。
   - Qiskit の Optimize1qGatesDecomposition は、照合の基準として使うだけにしてください。
5. **測定：** 書かれたままにします。項目 89（測定の直前の対角 Clifford を落とす）は、使っても使わなくても構いません。どちらにしたかを書いてください。

**テスト（範囲の中だけ）**

| 種類 | 回路 |
|---|---|
| CZ の鎖の ansatz | W4 の chain_cz_n12、n16 |
| CZ のリング | n = 12 |
| CZ のヘビーヘックス区画 | n = 16、20（C57-VAL の辺） |
| CX の鎖 | 層ごとに cx(q, q+1) |
| Qiskit の部品 | `real_amplitudes` と `efficient_su2`（entanglement="linear"、reps 2・4、n = 8、12、16）。ライブラリの部品は、展開してから入力にしてください。 |

**機械：** C57-VAL の 5 台、それぞれ T と F。

**事前に固める合格の基準（案です。固める前に直して構いません）**

- 出力はすべて、項目 93 で正確（20 アクティブ量子ビット以下）、ネイティブ、壊れた素子なし、rzz が範囲内であること。

### W2（W1 の後）項目 100：試作 c61（c60 から）。コンパイラの型

**理由**

- 家で測りました。c59 の式の経路は、tfim_n40_r2（F）で 1 回 93 ms かかります（プロファイラなし、5 回の中央値）。
- そのうち Qiskit の中にいるのは 4〜13% だけで、残りは PSF 自身の読み取りと組み立てです。
- 変分ループや、時間の点を変えて回す Trotter では、形は同じで角度だけが変わります。毎回組み直す必要はありません。

**API**（a20 の `RingTemplate` に合わせてください）

- `compile_template(qc, target, seed_transpiler=0)` は `CompileTemplate` を返します。メソッドは `.values_of(qc)`、`.bind_values(values)`、`.bind(qc)`、`.signature` です。
- 対象は、c60 が組める範囲の中の入力すべてです（鎖、グラフ、項目 99）。

**守ること**

- **組むのは 1 回だけです。** 角度の差し替えは閉じた形だけで行います。Qiskit のパスマネージャもシミュレーションも使いません。
- **形の署名：** 形を変えうるものは、すべて署名に入れてください。署名が変わったら組み直し、数えてください。間違った出力を返すことは、決してしないでください。
  - 項目 88 のパウリフレームは、rzz の角度の符号で形が変わります。
  - F では、項目 86 の折り返しが角度の範囲で変わります。
  - 係数が 0 になると項が消えます。
  - 式が角度で分岐している所が、ほかにもあるかもしれません。洗い出してください。
- 同じ角度なら、c60 の出力と一字一句同じであること（value_sig）。それが無理な場所は、理由を書いたうえで、項目 93 で正確、かつ回路時間と2量子ビット数が c60 と同じであること。

**事前に固める合格の基準（案）**

- テストごとに、同じ署名の乱数の角度を 1000 組試します。すべてが上の一致の条件を満たすこと。
- 差し替えの時間の中央値：n ≤ 20 なら 2 ms 以下、n = 40 なら 5 ms 以下。Qiskit の差し替え（`assign_parameters`）の時間も並べて報告してください。
- 組む時間：c60 の 1 回のコンパイルの 2 倍以下であること。
- 10 万回の差し替え（`benchmarks/template_100k.py` と同じ形）：1 つの鎖で T と F。最悪の誤差と、メモリが増えないことを確認します。

**テスト：** C58-VAL の範囲内の 12 テスト（tfim の鎖、tfimP、heis の鎖、tfim_n40、hhI_n16・20、ring12、hhtree_heis）と、W1 の CZ・CX の ansatz です。機械は FakeFez の T と F で十分です。正しさだけは、5 台で確認してください。
