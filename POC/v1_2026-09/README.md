# POC kit of September 2026 (kept for the record)

This folder holds the proof-of-concept kit and overview of September 2026, moved here unchanged on 2 November 2026.
It is about Papers 1 and 2: analytic two-qubit gate synthesis, and the failures of Qiskit's VF2 layout search on
saturated coupling maps. Its numbers are the records of that time. They have not been checked again since, and are
neither confirmed nor withdrawn here.

The kit needs PSF-Zero's Rust core to be built (`maturin develop --release`). It was not run when it was moved.

Its own instructions are in `poc_kit_README.md`. The request form and report template of that time
(`psf_zero_poc_request_form.docx`, `psf_zero_poc_report_template.docx`) were moved here too. The current entry point is [`../README.md`](../README.md).
